🧠 Definition: What is an Array?

An array is a collection of elements (like numbers, characters, or objects) stored in contiguous memory locations and accessed using an index.

In simple terms —
➡️ An array is like a row of boxes, where each box stores a value, and you can quickly access any box using its number (index).


Declare an array:
int[] numbers = new int[5];  
Creates an array of 5 integers

Initialize with values:
int[] numbers = {10, 20, 30, 40, 50};


Access elements:

prints 10
System.out.println(numbers[0]); 

prints 40
System.out.println(numbers[3]); 

⚙️ Array Index

Index starts at 0

So if you have 5 elements → indices are 0, 1, 2, 3, 4


⚡ Complexity Summary
Operation	Time Complexity
Access	O(1)
Search (Linear)	O(n)
Search (Binary)	O(log n)
Insert / Delete	O(n)
Reverse	O(n)
Sort	O(n log n)


🧮 Common Utility Functions (Java’s Arrays Class)
Function	Description
Arrays.sort(arr)	Sorts the array
Arrays.copyOf(arr, n)	Copies array
Arrays.equals(a, b)	Compares two arrays
Arrays.fill(arr, x)	Fills all elements with x
Arrays.binarySearch(arr, key)	Searches element in sorted array
Arrays.toString(arr)	Converts to printable string



📦 Types of Arrays in Java

One-Dimensional Array
Example: int[] arr = {1, 2, 3, 4};

Two-Dimensional Array (like a matrix)
Example:
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(matrix[1][2]); // prints 6

⏱️ Advantages

✅ Fast access (O(1) time using index)
✅ Easy to use
✅ Good for storing fixed-size data

⚠️ Disadvantages

❌ Fixed size (you can’t expand it later)
❌ Inserting or deleting elements in the middle is slow
❌ Same data type only
